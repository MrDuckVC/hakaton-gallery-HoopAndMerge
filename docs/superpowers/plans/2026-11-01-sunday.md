# Sunday backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Реализация runtime этим изменением не выполняется.

**Goal:** согласованное расширение готовой галереи №2–14: admin, FPS/ping, светильник, NPC, эффекты гидов.

**Architecture:** неизменяемый C01 + сохраняемый room/profile overlay, consumer-owned порты во внутренних слоях. Полные runtime snapshots, CAS, один writer; NPC/telemetry в RAM. Связывание только cmd/server.

**Tech Stack:** существующие Go net/http, pgx/v5, coder/websocket, PostgreSQL, Ollama; frontend Three.js отдельно.

**Spec:** [нормативный Sunday-контракт](../../api/sunday.md), типы/схемы/examples рядом; задачи [SUNDAY_BACKLOG.md](../../SUNDAY_BACKLOG.md).

## Global Constraints

- На всё 7 часов при параллельном backend/frontend; последние 2 часа — интеграция/показ. Оценки ниже ориентировочные, не обещание сроков.
- Не менять миграции 00001–00005, файл C01/WORLD_VERSION и базовые HTTP/WS payload.
- Только FPS+ping в admin; никаких новых моделей/текстур/physics, legacy endpoints или framework.
- Owning/ready/epoch/connection ID, no mutex на I/O, commit до broadcast, context/deadline.
- Без commit/push/PR/merge в рамках подготовки контрактов/задач. Runtime отдельно.

## Review Focus

- Старый callback release/metrics после replacement не меняет новую сессию: тесты S03/S04.
- Unknown COMMIT и потери ответов не превращаются в запись старого состояния: CAS/reconnect тесты S01/S04/S06.
- Редактор/гид и игра пользуются одинаковым effective placement: distance/LOS тесты S01/S02/S06.
- Незавершённая/следующая генерация не смешивают версии профиля и персональную память: S02.
- Telemetry и массовые NPC не заполняют command budget/SQL/выходную очередь: S03/S05/S07.
